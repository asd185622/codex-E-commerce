# E-Commerce Backend System

A RESTful e-commerce backend system built with Spring Boot and MySQL.  
This project implements core e-commerce features, including user management, product catalog management, and order processing.

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Maven
- MySQL
- JUnit 5
springboot-mall/src/main/java/com/jerry/springbootmall
